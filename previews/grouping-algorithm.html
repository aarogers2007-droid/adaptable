Circle 2 — The Mind 5 archetypes · 3 required per group (★)

Immediately thinks about how to make the thing. Wants to know what it looks like and how it works.

systems_thinker ★

Diversity Score

chip_diversity = unique_chips / total_chips across the group. A group of 5 students where each picked different chips scores 1.0. A group where everyone picked the same 3 chips scores 0.33.

Cross-Group Voice Swaps

After initial group formation, the algorithm scans for groups missing visual or verbal coverage. If Group A needs a visual communicator and Group B has a spare, the algorithm swaps two students between groups — but only if the swap doesn't break Group B's coverage.

GROUP A — needs visual

S1 verbal S2 verbal S3 S4 verbal S5 ← out
⇄ swap

GROUP B — has spare visual

S6 visual S7 visual ← out S8 verbal S9 both S10

Result: S5 goes to Group B, S7 (visual) goes to Group A → both groups now have coverage

Pass / Fail Criteria

✓

Archetype Coverage

Group has at least one Builder, one Empath, and one Systems Thinker

✓

Scale Balance

No more than 3 students selected the same scale option (A/B/C/D)

✓

Visual Communicator

At least one student chose Draw it, Build a prototype, or Build a slide

✓

Verbal Communicator

At least one student chose Explain out loud or Write it out

✓

Minimum Group Size

Groups smaller than 3 are merged into the last group in their category pool

✓

all_criteria_met

True only when archetype coverage + scale balance + visual + verbal all pass

Merge Rule — Minimum Group Size

If fewer than 3 students remain in a category pool after groups are formed, they are merged into the last group in that pool rather than forming a tiny group. Composition metrics are recomputed after merge. This prevents groups of 1-2 which can't function as teams.
