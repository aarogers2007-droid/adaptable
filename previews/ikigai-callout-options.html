Ikigai — Callout Variations

You liked F (the callout lines). Here are 4 riffs on that idea, pushing it further.

F1 — Diagonal Corner Callouts

Lines shoot diagonally from each circle to the four corners. Color-matched to each circle. Labels sit in clean open space at the corners, far from the diagram. Feels like a technical spec sheet.

F3 — Line + Pill Terminus

Straight lines radiate outward from each circle (like F), but instead of bare text, each label is inside a subtle rounded pill that matches the circle's color. The line connects the diagram to a tangible "thing." Feels like a node graph or product feature map.
